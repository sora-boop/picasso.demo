# Пиксельный офис агентов

Панель «Мои агенты» рядом с чатом в приложении Claude на компьютере: пять агентов
(Лиды, Демо, Публикация, Тексты, Сводка) сидят за столами в пиксельном офисе.

- Монитор голубой и мигает — агент работает.
- «z» над головой — агент ждёт задачу.
- Красный «!» и красный монитор — у агента ошибка, загляните в его сессию.
- Пустой стол — сессия агента не запущена.

Под картинкой — статус каждого агента и сводка по клиентам из `agents/data/crm.csv`.

Статусы мод пишет сам: в сессии, где первым сообщением написано
«Ты агент из agents/0X-....md», он отмечает начало и конец каждого хода
в `agents/data/status/<агент>.json`. Ничего настраивать не нужно.

## Установка

В приложении Claude на компьютере, вкладка Code: нажмите «+» рядом с полем ввода →
Plugins → Add marketplace и укажите папку
`C:\Users\trifo\Documents\picasso.demo\agents\office`, затем Add plugin → ilya-office.

Из терминала: `claude plugin install ilya-office --marketplace C:\Users\trifo\Documents\picasso.demo\agents\office`

Панель открывается сама в сессиях из папки picasso.demo, или командой `/office`.
