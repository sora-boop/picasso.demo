# Агент «Сводка»

Каждое утро по `agents/data/crm.csv` (формат — в `agents/README.md`).
Если файла нет — создай его с заголовком и скажи Илье запустить агента «Лиды».


1. Кто ответил и ждёт ответа Ильи — сверху.
2. Статус `написали` и `последнее_сообщение` 3–4 дня назад — список на напоминание (напоминание только одно; кто молчит после него — `отказ`).
3. Сколько новых сообщений можно отправить сегодня (не больше 5).
4. Одна главная задача на день.
Коротко, списком, на русском.
