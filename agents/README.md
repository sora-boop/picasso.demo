# Агенты студии Ilya Web Design

Пять агентов для Claude Code на компьютере. Каждый агент — отдельная сессия
с одной задачей. Отправку сообщений в WhatsApp делаете вы сами, агенты только готовят.

| Агент | Файл | Что делает |
|---|---|---|
| Лиды | `01-lidy.md` | находит бизнесы без сайта в Рудном и Костанае |
| Демо | `02-demo.md` | собирает пример сайта под конкретный бизнес из шаблонов в `projects/` |
| Публикация | `03-publikaciya.md` | выкладывает демо на ilya-webdesign.netlify.app/demo/... |
| Тексты | `04-teksty.md` | пишет первое сообщение и ответы клиентам |
| Сводка | `05-svodka.md` | каждое утро: кто ответил, кому напомнить, что сделать |

## Как запустить

1. Установите приложение Claude для компьютера (claude.ai/download) и войдите.
2. Откройте вкладку **Code**.
3. Склонируйте этот репозиторий: «Открыть папку» → или в терминале
   `git clone https://github.com/sora-boop/picasso.demo.git`
   и переключитесь на ветку `claude/brave-tesla-1eoj1z`.
4. Для каждого агента откройте новую сессию в папке репозитория и первым
   сообщением напишите: `Ты агент из agents/01-lidy.md. Прочитай файл и начинай.`
   (номер файла меняйте под агента).
5. Общие данные агенты хранят в `agents/data/` (папка в .gitignore, в GitHub не уходит):
   - `leads.csv` — найденные бизнесы;
   - `crm.csv` — кому написали, кто ответил, статус.

- Не отправлять сообщения в WhatsApp, Instagram и куда-либо ещё от имени Ильи.
- Не публиковать демо с названием бизнеса, пока он сам не попросил пример.
- Цены: лендинг от 25 000 ₸, сайт для бизнеса от 35 000 ₸, сайт с 3D от 45 000 ₸,
  срочно 2–3 дня +20%. Оплата 50/50.
- Портфолио: https://ilya-webdesign.netlify.app
