# Pulse Arena — концепт сайта фитнес-клуба

Вымышленный клуб в Костанае. Демонстрационный проект для портфолио.

**Главное: 3D-гиря на Three.js и облако пульса.**
- Гиря собрана кодом, на ней надпись «24 KG».
- Вокруг 3 200 частиц. Каждый удар сердца проходит по облаку волной от центра наружу («тук-тук» и пауза).
- Внизу экрана живой пульсометр: линия ЭКГ и удары в минуту, синхронные с 3D.

**«Одна тренировка, четыре зоны».** Закреплённая сцена:
1. Разминка: 112 уд/мин.
2. Сила: 132 уд/мин, гиря качается маятником в темпе пульса.
3. Кардио: 164 уд/мин, облако разгоняется.
4. Восстановление: 92 уд/мин, облако затихает.

**Разделы:** первый экран (схема B) → четыре зоны → направления (фото меняется по наведению) → расписание по дням → абонементы → тренеры → зал (фото на весь экран + факты) → запись на пробную в WhatsApp → подвал.

В расписании кнопка «Записаться» сразу ставит направление, день и время в заявку.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки: `index.html`, `styles.css`, `script.js`, `bell.js`.

**Фолбэки:** без WebGL показывается `assets/bell.png`; при `prefers-reduced-motion` анимации отключены.

**Подстановка под клиента** (всё в начале `script.js`): `SITE`, `ZONES`, `PROGRAMS`, `CLASSES` (расписание по дням), `PLANS`, `COACHES`, `FACTS`.

**Фото:** Unsplash, заменить на фото клиента:
- `assets/coach-1..3.jpg` — тренеры;
- `assets/hall.jpg` — зал;
- `assets/gym.jpg`, `func.jpg`, `bells.jpg`, `box.jpg`, `stretch.jpg` — направления.
