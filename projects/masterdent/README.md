# Ақ Тіс Clinic — концепт сайта стоматологии

Вымышленная клиника в Костанае. Демонстрационный проект для портфолио.

**Главное: 3D-зуб на Three.js, собранный кодом.** Моляр с буграми, тремя корнями, пульпой и каналами.
- **Первый экран.** Под курсором открывается круглая рентген-линза: зуб становится прозрачно-голубым, внутри видны нерв и каналы. На телефоне линза сама ходит по зубу.
- **«Как мы лечим».** Закреплённая сцена из 4 шагов:
  1. Диагностика: по зубу проходит луч сканера и находит кариес.
  2. Лечение: кариес заполняется, вспыхивает синяя лампа.
  3. Имплантация: коронка поднимается, корни растворяются, вкручивается титановый имплант, коронка садится на него.
  4. Улыбка: блик по эмали и искры.

**Разделы:** первый экран (схема B) → как мы лечим → услуги и цены (4 вкладки) → врачи → клиника (фото на весь экран + факты) → запись к врачу в WhatsApp → подвал.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки: `index.html`, `styles.css`, `script.js`, `tooth.js`.

**Фолбэки:** без WebGL показывается `assets/tooth.png`; при `prefers-reduced-motion` анимации отключены.

**Подстановка под клиента:** название, WhatsApp, часы, услуги, врачи, факты и шаги — в начале `script.js` (`SITE`, `SERVICES`, `DOCTORS`, `FACTS`, `STEPS`).

**Фото:** Unsplash. Заменить на фото клиента:
- `assets/doc-1..3.jpg` — врачи;
- `assets/clinic.jpg`, `consult.jpg`, `xray.jpg`, `lobby.jpg` — клиника.
