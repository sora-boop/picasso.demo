# ҚАЙРАҚ: концепт сайта барбершопа

Вымышленный барбершоп в Рудном, проект для портфолио.

- 3D опасная бритва на Three.js (`razor.js`): геометрия, материалы и студийный свет построены кодом, без внешних моделей.
- Бритва одна на всю страницу и перемещается между секциями по скроллу.
- GSAP + ScrollTrigger: появление букв, манифест по словам, ритуал из 4 шагов, горизонтальная лента мастеров.
- Lenis: плавный скролл. Курсор с подписями и магнитные кнопки на компьютере.
- Онлайн-запись: услуга, мастер, день, время, заявка в WhatsApp.
- Без WebGL показывается `assets/razor.png`, при `prefers-reduced-motion` анимации появления отключены.

Открывать через локальный сервер (модули не работают с file://):

    python3 -m http.server 8000
