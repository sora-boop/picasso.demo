# Tobyl Coffee — концепт сайта кофейни

Вымышленная кофейня в Костанае. Демонстрационный проект для портфолио.

**Главное:** 3D-стакан на Three.js, собранный кодом без моделей.
- На первом экране горячий бумажный стакан с крафтовым рукавом и паром.
- При скролле бумага растворяется с тлеющим краем, под ней прозрачный стакан.
- В закреплённой тёмной сцене в нём собирается айс-латте: падает лёд, льётся молоко, эспрессо опускается облаками, сверху садятся купол и трубочка.
- Стакан всё время вращается от скролла и слушает курсор.

**Разделы:** первый экран (схема B) → айс-латте за 4 шага → меню с корзиной → своя обжарка (60/40) → место (фото на весь экран + галерея) → заказ навынос в WhatsApp → подвал.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки: `index.html`, `styles.css`, `script.js`, `cup.js`.

**Фолбэки:** без WebGL показывается `assets/cup.png`; при `prefers-reduced-motion` анимации отключены, сайт полностью рабочий.

**Подстановка под клиента:** название, телефон WhatsApp, меню и шаги — в начале `script.js` (`SITE`, `MENU`, `BREW`, `ORIGINS`). Надпись на стаканах — в `cup.js` (`printTexture`, `sleeveTexture`).

**Фото:** Unsplash. Заменить на фото клиента:
- `assets/place.jpg`, `tree.jpg`, `light.jpg`, `bar.jpg` — зал;
- `assets/beans.jpg` — обжарка;
- `assets/pour.jpg` — напиток.
