# Бакс: демо-сайт барбершопа

Барбершоп «Бакс», Астана, Сарайшык, ЖК «Азия Плюс», ул. Жумекена Нажимеденова, 16а.
Данные взяты из 2ГИС: адрес, часы 9:00–24:00, телефон и WhatsApp +7 701 820 05 55, рейтинг 5,0 (108 оценок, 86 отзывов), цены, имена мастеров и отзывы.

**Главное: 3D-машинка для стрижки** (`clipper.js`). Корпус, золотая голова с надписью «БАКС», ножи и насадки построены кодом.
- **Первый экран:** машинка стоит на стыке текста и фото.
- **«Шкала насадок»:** закреплённая сцена, на машинку по очереди надеваются насадки 0, №1–№4 с длиной в мм. Когда мотор включён, подвижный нож ходит, а светодиод горит.
- **Подвал:** машинка ложится поперёк слова «Бакс».

**Своё, чего нет в ҚАЙРАҚ:**
- светлая палитра;
- статус «Открыто до 24:00» по времени Астаны;
- шкала насадок;
- реальные отзывы из 2ГИС;
- прошедшие слоты «на сегодня» в записи недоступны.

**Разделы:** первый экран (схема C) → что входит в стрижку → насадки → цены → мастера → отзывы → где мы (фото на весь экран) → запись в WhatsApp → подвал.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки.

**Фолбэки:** без WebGL показывается `assets/clipper.png`; при `prefers-reduced-motion` анимации отключены.

**Подстановка:** всё в начале `script.js` (`SITE`, `VISIT`, `GUARDS`, `SERVICES`, `MASTERS`, `REVIEWS`).

**Заменить на фото барбершопа** (сейчас Unsplash):
- `assets/hero.jpg`: первый экран;
- `assets/hall.jpg`: зал;
- `assets/master-1..3.jpg`: Бауржан, Талгат, Ералхан.

Файлы `fade-*.jpg` и `work-*.jpg` сейчас не используются, это запас для галереи работ.
