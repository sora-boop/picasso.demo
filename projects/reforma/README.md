# ReForma — лендинг фитнес-студии

Костанай, проспект Абая, 161. Ежедневно 8:00–22:00 по записи. Instagram: @reforma_kst.

Простой лендинг по просьбе владелицы («не люблю, когда много напихано, главное — записаться»):
первый экран → направления → цены → расписание → как добраться (карта, 2ГИС, Яндекс) → призыв → подвал.

**Запись:** любая кнопка «Записаться», карточка направления или строка расписания открывает окно
записи (направление, время, имя) и ведёт в WhatsApp студии `wa.me/77052155625` с готовым текстом.
В демо-режиме (`SITE.demo = true` в `script.js`) сообщение не отправляется, а показывается его текст.

**Данные** (всё в начале `script.js`): `PROGRAMS`, `PRICES` (прайс от 1.10.2026), `SCHEDULE`.

**Подставить, когда пришлёт студия:**
- цена оздоровительной гимнастики;
- остальное расписание субботы и расписание воскресенья;
- фото зала вместо `assets/hall.jpg` (Unsplash).

Не писать про полотенца и бесплатную воду: студия их не выдаёт.

Без библиотек: `index.html`, `styles.css`, `script.js`.
