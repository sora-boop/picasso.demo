# Илья — портфолио

Сайт-портфолио: дизайн и разработка сайтов для бизнеса в Казахстане. Чёрный, белый и сигнальный оранжевый.

**3D (Three.js, без моделей):** «разобранная» страница сайта, окно браузера и слои макета.
- **Первый экран:** слои парят над окном белым каркасом, оранжевая кнопка светится, курсор ведёт за собой оранжевый свет.
- **«Как появляется сайт»:** в закреплённой сцене слои проходят 4 этапа: структура (каркас) → дизайн (заливка) → код (поток кода, слои складываются) → запуск (экран).
- **«Работы»:** экран показывает проекты по очереди и меняет их шторкой с оранжевой кромкой.

**Разделы:** первый экран → процесс → работы (5 крупно) → ещё работы (список) → принципы → цены → калькулятор стоимости → вопросы → заявка → подвал.

**Что заменить перед публикацией** (всё в начале `script.js` и в `index.html`):
- `ME.whatsapp` и `ME.telegram`, ссылки `wa.me/77000000000` и `t.me/username` в `index.html`.
- Цены (`PRICES`, `CALC`) и сроки (`PROCESS`) — сейчас примерные.
- Ссылки работ (`WORKS`, `MORE`) ведут на превью claude.ai. Откройте к ним доступ через Share или замените на свои домены.

**Скриншоты работ:** `assets/works/` (1440×900). Без WebGL показывается `assets/studio.png`.
