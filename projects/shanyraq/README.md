# Шаңырақ — концепт сайта ресторана казахской кухни

Вымышленный ресторан в Костанае. Демонстрационный проект для портфолио.

**Главное:** 3D-юрта на Three.js, собранная кодом без моделей. Юрта собирается при скролле в закреплённой сцене:
- на первом экране парит шаңырақ с күлдіреуіш и золотым орнаментом қошқар мүйіз;
- 56 уықтар по очереди прилетают и встают в обод;
- кереге (решётка) разворачивается от двери по кругу;
- киіз (войлок) с синей лентой опускается сверху;
- внутри зажигается свет: светятся шаңырақ и дверь, из купола идёт дым.

В меню шаңырақ показан снизу, как изнутри юрты, и сквозь него видно блюдо, на которое наведён курсор. В блоке брони стоит готовая светящаяся юрта.

**Разделы:** первый экран (схема B) → юрта за 4 шага → меню из 4 вкладок → тои и банкеты (фото на весь экран + три зала) → бронь стола в WhatsApp → подвал.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки: `index.html`, `styles.css`, `script.js`, `yurt.js`.

**Фолбэки:** без WebGL показывается `assets/yurt.png`; при `prefers-reduced-motion` анимации отключены.

**Подстановка под клиента:** название, WhatsApp, часы, меню, залы и шаги — в начале `script.js` (`SITE`, `MENU`, `STEPS`, `HALLS`). Фото блюд для шаңырақа — массив `DISHES`, у каждого блюда в меню поле `img` с индексом фото.
