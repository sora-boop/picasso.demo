# TORQUE 52 — концепт сайта автосервиса

Вымышленный автосервис в Рудном. Демонстрационный проект для портфолио.

**Главное: 3D тормозной узел на Three.js, собранный кодом.** Вентилируемый перфорированный диск, ступица со шпильками и гайками, жёлтый суппорт, колодки.
- **Первый экран.** Колесо крутится от скролла. Если листать быстро, диск раскаляется до оранжевого свечения.
- **«Тормоза за час».** Закреплённая сцена из 4 шагов:
  1. Диагностика: на диске проступает ржавчина, колодки стёрты.
  2. Разбор: гайки вылетают, суппорт уходит вверх, колодки разъезжаются, ступица отходит назад. У каждой детали подпись с ценой работы.
  3. Замена: диск становится чистым, колодки новыми.
  4. Сборка: всё возвращается на место.

**Разделы:** первый экран (схема B) → тормоза за час → прайс (5 вкладок) → калькулятор ремонта → гараж (фото на весь экран + факты + галерея) → запись в WhatsApp → подвал.

**Технологии:** Three.js 0.160, GSAP + ScrollTrigger, Lenis. Без сборки: `index.html`, `styles.css`, `script.js`, `brake.js`.

**Фолбэки:** без WebGL показывается `assets/brake.png`; при `prefers-reduced-motion` анимации отключены.

**Подстановка под клиента** (всё в начале `script.js`):
- название, WhatsApp, часы — `SITE`;
- прайс — `SERVICES`;
- калькулятор — `CALC`: работы, часы, коэффициенты по типу машины;
- подписи деталей — `PARTS`;
- шаги и факты — `STEPS`, `FACTS`.
