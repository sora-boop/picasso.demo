# Шаблон: салон красоты, парикмахерская, барбершоп

Одна вёрстка, три пресета. Пресет задаёт тексты, услуги с ценами, фото и цвета.

| Пресет | Для кого | Лиды |
|---|---|---|
| `barber` | барбершопы, мужские парикмахерские | OLDBOY, ARISTOKRAT, Bradobrey |
| `hair` | парикмахерские, салоны с упором на волосы | «Прованс», «Шик» |
| `beauty` | ногти, брови, ресницы, косметология | Prestige, «Нефертити» |

Если у салона есть и волосы, и ногти, берите `hair` и добавьте в `services` категорию «Ногти» из пресета `beauty`.

## Что на странице

1. Первый экран: текст слева, фото справа во всю высоту. Кнопка «Записаться онлайн».
2. Короткий текст о салоне и 4 цифры: рейтинг 2ГИС, годы работы, число мастеров, часы.
3. Услуги и цены по вкладкам. При смене вкладки фото открывается шторкой. Нажатие на услугу переносит её в форму записи.
4. Галерея работ: листается пальцем и стрелками.
5. Мастера. «Записаться к мастеру» подставляет мастера в форму.
6. Онлайн-запись: услуга, мастер, день (7 ближайших), время (прошедшее сегодня недоступно), имя, телефон с маской. Заявка уходит в WhatsApp салона готовым сообщением.
7. Рейтинг и кнопка «Читать отзывы в 2ГИС». Если вставить настоящие отзывы в `reviews`, появится лента цитат.
8. Контакты с фото зала и маршрутом в 2ГИС.

## Как подставить клиента

Всё меняется в блоке `CONFIG` в начале `script.js`:

```js
const CONFIG = {
  preset: 'hair',
  name: 'Шик',
  city: 'Рудный', cityIn: 'в Рудном',
  phone: '+7 705 123 45 67',
  whatsapp: '77051234567',
  instagram: 'https://instagram.com/shik_salon',
  gis: 'https://2gis.kz/rudnyy/firm/...',
  address: 'ул. Ленина, 12',
  hours: 'Ежедневно с 9:00 до 20:00',
  open: { from: 9, to: 20, step: 30 },
  rating: '4.8', ratingCount: 156, years: 9,
  colors: { bg: '#f3efe9', ink: '#211d19', accent: '#8c5a3c', onAccent: '#f7f3ee', scheme: 'light' },
  photos: { hero: 'assets/client/hero.jpg', place: 'assets/client/place.jpg' },
  team: [{ name: 'Алина', role: 'Колорист, 10 лет', photo: 'assets/client/alina.jpg' }],
  reviews: [{ text: '...', author: 'Айгерим', date: 'октябрь 2026' }],
};
```

Цвета: `bg` — фон, `ink` — текст, `accent` — главная кнопка, `onAccent` — текст на ней, `scheme` — `dark` или `light`. Больше трёх цветов не добавляйте.

## Фото

Демо-фото лежат в `assets/barber`, `assets/hair`, `assets/beauty`. Все взяты с Unsplash, лицензия разрешает коммерческое использование без указания автора. Для клиента их стоит заменить на фото из его 2ГИС или Instagram:

- `hero` — вертикальное, мастер за работой или результат;
- `place` — зал, горизонтальное;
- фото категорий услуг (поле `photo` в `services`) — крупные планы, вертикальные 4:5;
- мастера — по одному фото на мастера, вертикальное;
- галерея `works` — 5–8 работ.

На одном сайте свет на всех фото должен быть одинаковым: все тёмные и тёплые, либо все светлые.
